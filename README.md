# TWO26 DRIVE — Luxury & Exotic Car Rental Studio

> **"Driving Suspiciously Good"** — An unapologetic boutique exotic and classic car rental web platform engineered for pure driving joy, zero fluorescent counter queues, and instant curbside handover.

Built with **Next.js 16 (Turbopack)**, **React 19**, **TypeScript**, **Tailwind CSS**, **GSAP / ScrollTrigger**, **Lenis Smooth Scroll**, and **Web Audio API**.

---

## 🏎️ Key Features

- **Kinetic Motion Design System:** Inspired by the award-winning design language of [Two26 Studio](https://two26.studio/) and Rekeep, featuring signature warm-cream (`#FDF8F5`), high-contrast dark green (`#0F1E13`), and electric studio orange (`#FF5400`).
- **Authentic Typography:** Powered by `MD Nichrome Bold` clamp display typography and `Neue Montreal` body copy.
- **Winding Canyon Road SVG Follower:** Interactive SVG curved path with GSAP ScrollTrigger follower physics, taking drivers through 4 rental journey checkpoints.
- **Web Audio API Engine Sound Synthesizer:** Real-time dual-oscillator V8 engine throttle harmonics and acoustic click feedback with mute toggle.
- **Curated Exotic & Classic Stable:**
  - Porsche 911 GT3 RS (992) — 518 HP Shark Blue
  - Ferrari 296 GTB Assetto Fiorano — 819 HP Twin-Turbo Hybrid
  - Ford Bronco 1974 Restomod — 460 HP Coyote V8 Open-Air Safari
  - Mercedes-AMG G63 — 577 HP V8 Biturbo
  - Aston Martin Vantage V8 — 656 HP
  - Corvette Z06 (C8) — 670 HP Flat-Plane V8
- **Interactive Fleet Preview & Digital Cockpit:** Live smartphone mockup with keyless curbside unlock simulator and sound effects.
- **3-Step Reservation Flow:** Real-time pricing calculator, insurance package selection, airport/hotel concierge handover, and confirmation pass.
- **Engineered Footer:** Dual-column closing section with direct chassis cards, instant NFC Apple/Google Wallet QR code block, and giant watermark branding.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **UI & State:** React 19, TypeScript
- **Styling:** Tailwind CSS + Custom High-Fidelity CSS Design Tokens
- **Kinetic Animations:** GSAP (GreenSock), ScrollTrigger, Lenis Smooth Scroll
- **Audio Engine:** Native Web Audio API (`AudioContext`, Sawtooth & Triangle Oscillators)
- **Icons:** Lucide React & Handcrafted Vector Artwork

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone git@github.com:sahilshingate01/Car-Rent.git
cd Car-Rent
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or port configured) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
